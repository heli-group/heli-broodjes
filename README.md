# Heli broodjes bestellen (versie met Supabase)
Statische pagina voor GitHub Pages. Zie `config.js` voor de instellingen.
- `demo: true` = testmodus (geen echte bestellingen).
- `supabaseUrl` en `supabaseKey` invullen en `demo: false` = echte bestellingen via Supabase.
- Zet nooit een geheime sleutel in `config.js`: dit bestand is openbaar.
