# Heli · Broodjes bestellen

Statische bestelpagina voor lesgevers, personeel en broodjes-beheerders.

- `index.html` – de pagina zelf
- `config.js` – enige bestand dat je aanpast (testmodus aan/uit en het webadres van de flow)
- `app.js`, `app-admin.js` – de schermen
- `api.js` – praat met de flow
- `demo.js` – testmodus; beschrijft ook exact wat de flow moet antwoorden
- `test.html` – test of de koppeling met de flow werkt
- `style.css` – opmaak

Alles in deze map is openbaar leesbaar. Zet hier nooit wachtwoorden of sleutels in.
Het webadres van de flow staat wel in `config.js`: de flow controleert zelf elke bestelling.
